# Screen recording checklist (target: 5–10 minutes)

**Only record screens that are actually functioning.** Do not read a generated sample answer as if it came from MeetUniversity leadership. Operator-provided answers can be clearly identified as demonstration input. Set the system to work with safe public sources, and hide API keys, passwords, database strings and internal documents in the recording.

| Minute | What to demonstrate | Verifiable proof |
|---|---|---|
| 0:00–0:45 | Enter or select MeetUniversity; research homepage | Original site link; verified claims vs assumptions |
| 0:45–2:30 | Complete the ten-question adaptive interview | Each question created after the preceding answer; distinct topics and follow-up behavior |
| 2:30–3:30 | Change company context and audit its sources | Before/after context; changed source relevance; new candidates |
| 3:30–4:45 | Discover and review four intelligence categories | 20+ approved MeetUniversity sources, 5–10 real competitor profiles, primary websites and inclusion reasons |
| 4:45–5:50 | Monitor approved sources | Source crawl history, duplicates, dated real records, direct quotation and URLs |
| 5:50–7:10 | Open the ten-part Monday brief | Synthesis, previous-week comparison, relevant opportunities/risks, ranked actions, complete source appendix |
| 7:10–8:10 | Upload an authorised internal TXT/CSV and consent | Extracted chunk evidence, internal insights, data provenance |
| 8:10–9:20 | Switch to Ghost and Fairphone | Different business model, source sets, competitors and historical/current reports |
| 9:20–10:00 | Trigger monthly audit and show automation history | Health, retry/failure status, Action/Render setup and scheduled worker |

If a section has no current evidence, explain it honestly and show the historical source archive rather than pretending a 2017 post was discovered as this week's news. Before recording, complete authentic answers, approve live primary sources and run fresh monitoring for each company; this cannot be truthfully pre-recorded offline.
